# 数独 Sudoku

单文件、零依赖的网页数独。打开即玩，无需安装与构建。

[在线试玩](https://hypodear.github.io/mini-game/sudoku/)

## 特点

**难度按解题技巧分级，而非按挖空数量**

常见的数独生成器用「挖掉多少格」定义难度，但实际难度取决于「需要用到多高阶的推理技巧」。本项目内置六级技巧求解器，生成盘面时模拟人类推理过程，按实际所需技巧定级：

| 难度 | 技巧区间 | 涉及技巧 |
|------|----------|----------|
| 简单 | L1–L2 | 唯一候选数、隐性唯一数 |
| 中等 | L3–L4 | 区块排除、显性数对/三元组 |
| 困难 | L4–L6 | 显性数对、隐性数对、X-Wing |

**保证纯逻辑可解，永不需要猜测**

生成时每挖去一格都会验证剩余盘面仍能被纯逻辑推导解出，不满足则放回。同时用回溯计数校验解的唯一性。玩家卡住一定是技巧未到位，而非题目本身无解。

**其它**

- 响应式布局，适配手机与桌面
- 选中格高亮同行同列同宫，相同数字联动高亮
- 实时冲突检测标红
- 自动本地存档，刷新不丢进度
- 尊重系统的「减少动态效果」偏好设置

## 玩法

- 点击格子选中，再点数字键或按键盘 `1`–`9` 填入
- 再次点击同一数字即可清除，也可按 `Backspace` / `Delete` / `0`
- 方向键可移动选中格
- 点击难度按钮开始新的一局

## 本地运行

无需任何依赖，直接用浏览器打开 `index.html` 即可。

若需本地起服务：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 技术说明

整个游戏是一个 HTML 文件，约 22 KB，不依赖任何框架或运行时库。

代码分为两层，逻辑层与渲染层完全分离：

- **逻辑层**：棋盘表示、候选数计算、回溯求解、六级技巧求解器、技巧约束生成。全部为纯函数，不接触 DOM，可独立抽出做单元测试。
- **渲染层**：状态渲染、输入处理、本地存档。

技巧求解器实现的六级推理：

1. 唯一候选数（Naked Single）
2. 隐性唯一数（Hidden Single）
3. 区块排除（Locked Candidates，含 Pointing 与 Claiming）
4. 显性数对 / 三元组（Naked Pair / Triple）
5. 隐性数对 / 三元组（Hidden Pair / Triple）
6. X-Wing
