# 数独

单文件、零依赖的网页数独。

[在线试玩](https://hypodear.github.io/mini-game/sudoku/)

## 特点

**难度按解题技巧分级，而非按挖空数量**

常见做法用「挖掉多少格」定义难度，但实际难度取决于「需要用到多高阶的推理技巧」。本项目内置六级技巧求解器，生成时模拟人类推理过程，按实际所需技巧定级：

| 难度 | 技巧区间 | 涉及技巧 |
|------|----------|----------|
| 简单 | L1–L2 | 唯一候选数、隐性唯一数 |
| 中等 | L3–L4 | 区块排除、显性数对 |
| 困难 | L4–L6 | 显性数对、隐性数对、X-Wing |

**保证纯逻辑可解**

每挖去一格都验证剩余盘面仍能被纯逻辑解出，不满足则放回，同时校验解的唯一性。卡住一定是技巧未到位，而非题目无解。

## 玩法

- 点击格子选中，再点数字键或按键盘 `1`–`9` 填入
- 再次点击同一数字即可清除，也可按 `Backspace` / `Delete` / `0`
- 方向键移动选中格，点击难度按钮开始新局

## 技术

单个 HTML 文件约 20 KB，无框架无依赖。逻辑层（棋盘表示、候选数计算、回溯求解、技巧求解器、约束生成）为纯函数，不接触 DOM；渲染层独立。

六级技巧：唯一候选数、隐性唯一数、区块排除（Pointing / Claiming）、显性数对与三元组、隐性数对与三元组、X-Wing。
