# mini-game

开源小游戏合集。纯静态、零依赖、开箱即玩。

每个游戏都是独立的单文件 HTML，不依赖任何框架或构建工具，可直接用浏览器打开，也可部署到任意静态托管。

## 游戏列表

| 游戏 | 说明 | 在线试玩 |
|------|------|----------|
| [数独 Sudoku](sudoku/) | 按解题技巧分级难度，保证纯逻辑可解、无需猜测 | [开始游戏](https://hypodear.github.io/mini-game/sudoku/) |

## 在线地址

https://hypodear.github.io/mini-game/

## 本地运行

直接用浏览器打开对应游戏目录下的 `index.html` 即可。

若需本地起服务：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
