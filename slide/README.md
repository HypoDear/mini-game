# 滑块拼图

单文件、零依赖的网页滑块拼图（数字华容道式），三档棋盘、两种牌面。

[在线试玩](https://hypodear.github.io/mini-game/slide/)

## 特点

**开局保证可解**

打乱用「从已解态出发的随机游走」并禁止立即回头，因此**任何局面都在可解空间内**——不会出现滑块拼图经典的「剩下两块永远换不过来」的奇偶死局。

打乱后还会排除「恰好回到已解」这一退化结果（实测约 1/20 万局），所以开局一定是一盘待解的棋。

**复原会倒放你的每一步**

「复原」不是重开，而是沿**你自己的操作记录**逆序倒放回初始局面，并带滑行动画。步数越多倒放越快（>200 步时加速），不会让你干等。

## 难度

| 难度 | 棋盘 | 打乱步数 |
|------|------|----------|
| 三阶 | 3×3 | 108 |
| 四阶 | 4×4 | 192 |
| 五阶 | 5×5 | 300 |

## 牌面

| 牌面 | 说明 |
|------|------|
| 数字 | 牌面直接显示数字，归位的块底色变浅绿 |
| 双色 | 行色 + 列色叠加成色块，归位的块出现绿色描边环 |

## 玩法

点击与空格相邻的块即可滑动；也支持方向键（上下左右按「把哪边的块推过来」理解）。走不通的方向会轻微抖动提示。

**归位高亮**：处于正确位置的块会高亮，帮你判断进度。

## 技术

单个 HTML 文件约 25 KB，无框架无依赖，可直接用浏览器打开。

- **可解性**：随机游走 + 禁止立即回头，天然落在可解空间；比「生成随机排列再判断奇偶」更省事，也不需要重试
- **复原**：维护一个操作栈，复原时逆序回放，每步都是合法滑动
- **进度**：局面、操作栈、步数自动存入 `localStorage`，关掉再打开可以接着玩
- **音效**：WebAudio 现场合成（振荡器 + 噪声），无需任何音频文件；可一键关闭，偏好记忆
- **无障碍**：牌面与开关带 ARIA 角色，尊重系统的「减少动态效果」偏好
