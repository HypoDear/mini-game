# 连连看

单文件、零依赖的网页连连看，汉字牌面。

[在线试玩](https://hypodear.github.io/mini-game/llk/)

## 特点

**保证全程可解，不会死局**

多数连连看卡住后要靠玩家手动洗牌。本项目在两处做了校验：

- 生成牌面后验证存在可消对，不满足则重新铺排
- 每次消除后扫描全盘，无可消对时自动重排剩余牌并再次校验

玩家不会遇到"剩一堆牌却无法消除"的局面。

**路径规则**

支持直连、一次转折、两次转折，且允许绕出棋盘外围——否则边角的牌几乎无法消除。

## 难度

| 难度 | 棋盘 | 图案 | 机制 |
|------|------|------|------|
| 简单 | 8×6 | 12 种 | 静态布局 |
| 中等 | 10×8 | 16 种 | 静态布局 |
| 困难 | 12×8 | 18 种 | 消除后向左上收拢，局面持续重组 |

## 玩法

点击两张相同的汉字，若路径可连则消除。路径不通或字不同会轻微抖动提示。

## 技术

单个 HTML 文件约 20 KB，无框架无依赖。

- **路径判定**：按 0/1/2 次转折分层检查，比通用广度搜索更快且贴合规则
- **牌面**：24 个常用汉字，选字时避开了字形相近的组合
- **渲染**：牌面用常规元素承载，连线单独叠一层矢量图形绘制折线
- **动效**：选中上浮、消除旋转淡出、连线逐段绘制，均尊重系统的减少动态效果偏好
