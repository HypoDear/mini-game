# 五子棋

单文件、零依赖的网页五子棋，15×15 标准棋盘。

[在线试玩](https://hypodear.github.io/mini-game/gomoku/)

## 特点

**三档 AI，棋力真实递进**

| 难度 | 机制 |
|------|------|
| 入门 | 棋型评估 + 贪心落子，会漏防活三 |
| 进阶 | 浅层搜索，能攻能守，不做深度算杀 |
| 高手 | 深搜 + 算杀 + 置换表，会主动制造双威胁 |

高手档在自对弈测试中对进阶档保持全胜，单步响应平均 120 毫秒。

**可选禁手规则**

默认关闭，开启后对黑棋判三三禁、四四禁、长连禁，白棋不受限制。成五优先于禁手判定。

## 玩法

- 点击棋盘交叉点落子
- 可选人机（执黑或执白）与双人同屏两种模式
- 最后一手带标记，获胜时连线高亮

## 技术

单个 HTML 文件约 19 KB，无框架无依赖。AI 由四部分组成：

- **棋型评估**：按活四、冲四、活三、眠三等形态分级打分，攻守权重分离
- **Minimax + α-β 剪枝**：迭代加深至 6 层，超时自动回退上一轮结果
- **VCF 算杀**：独立搜索冲四、活三等强制手，寻找必胜路径
- **Zobrist 置换表**：缓存已搜索局面，提升剪枝效率

候选点裁剪到已有棋子周围两格内，并按评估分排序以加快剪枝。
