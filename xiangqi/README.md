# 中国象棋

单文件、零依赖的网页中国象棋，标准 9×10 棋盘。

[在线试玩](https://hypodear.github.io/mini-game/xiangqi/)

## 特点

**双人对战与人机对战，三档 AI 棋力真实递进**

| 难度 | 机制 | 搜索深度 |
|------|------|----------|
| 入门 | 仅子力价值，不查位置表，同分着法随机选择 | 2 层 |
| 进阶 | 子力 + 位置价值表，积极吃子与兑换，会抓明显漏子 | 4 层 |
| 高手 | 全部搜索优化，主动谋子、制造双重威胁 | 迭代加深，上限 8 层 |

高手档单步思考上限 2 秒，到点即回退上一轮迭代结果。搜索按深度分片执行，思考期间界面保持可响应，不会卡顿。

**完整的走法规则**

車炮滑行、馬的蹩马腿、象的塞象眼与不过河、士象的宫位限制、兵卒的过河横走与永不后退、将帅照面的白脸将，全部按规则判定。被将军时只能应将，将死与困毙均判负。

**循环局面有裁决**

同一局面第三次出现时判和；若循环中只有一方步步将军，判长将方负；六十回合无吃子判和。

## 玩法

- 点击棋子选中，再点目标位置走棋；合法落点以圆点标出，可吃子以红圈标出
- 双人对战：红黑轮流操作
- 人机对战：可选执红或执黑，切换后棋盘自动翻转视角
- 提示：为当前一方推荐一手
- 悔棋：双人模式退一手，人机模式退回到自己上一手
- 残局：内置八个练习局面，红先取胜
- 让子：可让左马、双马或左车
- 快捷键：`U` 悔棋，`H` 提示，`Esc` 取消选中

## 辅助

- 人机对战中，走出损失较大的一手时给出轻提示
- 局中自动存档，重新打开浏览器可继续

## 技术

单个 HTML 文件约 57 KB，无框架无依赖。逻辑分层：

- **规则层**：棋盘为 16×16 一维数组加边界哨兵，走法生成先出伪合法着法，再统一过滤自将，避免在生成阶段重复判定
- **评估层**：七种棋子各一张位置价值表，与子力值合并为单表查询；残局阶段自动调整马炮的相对价值
- **搜索层**：迭代加深 Negamax + α-β 剪枝，配合置换表（Zobrist 哈希）、主要变例搜索、静态搜索、着法排序（置换表着法优先、按被吃子价值排序的吃子着法、杀手着法、历史表），并带将军延伸与重复局面检测
- **渲染层**：棋盘用矢量绘制，棋子用常规元素承载汉字，二者共享同一坐标空间，便于动画与无障碍
- **开局库**：十条常见开局线路，前四手内命中即走，避免开局雷同

规则层与搜索层均为纯函数、不接触 DOM，可被自对弈脚本与校验脚本直接调用。
