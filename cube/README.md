# 魔方

单文件、零依赖的网页魔方，三阶 / 四阶 / 五阶。

[在线试玩](https://hypodear.github.io/mini-game/cube/)

## 特点

**拖动即转层**

在色块上滑动就转动对应的一层，在空白处拖动则旋转视角。方向判定按「色块跟着手指走」来算：把该层转动的位移投影到屏幕上，取与手势最贴合的那个轴与方向，所以横拖、竖拖、斜拖都能得到符合直觉的结果，不会出现「往右拖却往左转」。

**复原是倒放你的操作**

「复原」不是重开，而是沿**你自己的操作记录**逆序倒放回初始局面，并带转动动画。步数越多倒放越快（最长的一串会加速），不用干等。打乱之后直接点复原，则会倒放整个打乱序列。

**真实的塑料质感**

每个小方块都是 6 个深色面围成的闭合盒体，贴纸再往里内缩一点，于是缝隙处看到的是实体而不是黑的空洞——转动过程中也不会从缝里看穿到另一侧。

| 阶数 | 打乱步数 |
|------|----------|
| 三阶 | 25 |
| 四阶 | 35 |
| 五阶 | 45 |

## 玩法

在色块上朝任意方向滑动即可转层；在色块以外的空白处拖动可以旋转视角，方便看背面和底面。

**步数**：每次手动转层 +1，打乱与复原不计入。

**音效**：每次转层是「摩擦滑动 + 落位咔哒」两层叠加，音高随步数递升，避免长时间操作听感单调；右上角开关可一键关闭，偏好记忆。

## 技术

单个 HTML 文件约 33 KB，无框架无依赖，可直接用浏览器打开。

- **纯 CSS 3D**：每个小方块是一个 `preserve-3d` 容器，六个面用 `rotateX/Y + translateZ` 摆位，整机视角由外层 `rotateX/rotateY` 控制，没有 canvas 也没有 WebGL
- **状态与渲染同源**：贴纸颜色由一份面×格的状态数组驱动，转动时先跑置换更新状态，再把方块坐标搬到对应格子，两者用同一套坐标口径，不会出现「看到的盘面和记录的对不上」
- **动画不穿模**：转层时把该层方块临时移进一个绕轴旋转的容器，转完再按新坐标归位；缓动带一点收尾回弹，落位利落
- **进度**：盘面、操作栈、步数、视角自动存入 `localStorage`，关掉再打开可以接着玩
- **音效**：WebAudio 现场合成（噪声过带通模拟摩擦 + 三角波敲击），无需任何音频文件
- **无障碍**：分段切换与音效开关带 ARIA 角色，尊重系统的「减少动态效果」偏好
